# Twitter/X Thread 风格指南

## 第一条推文（Hook Tweet）
- 这是决定是否有人点开整个 thread 的唯一因素。必须独立成立、制造信息缺口（curiosity gap）。
- 常见结构："I did X for Y time. Here's what happened."（做了某事一段时间的反直觉结果）、"N lessons from doing X"（数字化的教训清单）、直接给出一个反常识断言，然后说"here's why 🧵"。
- 结尾用 "🧵" 或 "A thread:" 明确提示这是一个线程，提高展开率。
- 控制在 240 字符以内，短促有力，不要塞满 280 字符上限。

## 后续每条推文
- 每条只讲一个点，独立可读（有人可能只看到中间一条转发）。
- 用短句、断行制造呼吸感，避免大段文字；可用 "→" "1/" "2/" 等做轻量编号。
- 每隔几条插入一个具体例子/数字/引用增强可信度，避免全是空泛观点。
- 语气直接、略带态度，可以有个人观点甚至争议性视角（这是 Twitter 算法喜欢的），但要基于原文事实，不编造。

## 结尾条
- 总结核心 takeaway 一句话。
- CTA：如果有相关产品/账号，可以自然带一次（"If you build X, I write about Y every week — follow for more"），不要每条都硬广。
- 可以加一句 "If this was useful, RT the first tweet to help others find it."

## 篇幅
- 一般 5-12 条为宜，太短像单条推文没必要开 thread，太长完读率骤降。
