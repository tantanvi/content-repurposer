# 短视频口播稿风格指南（抖音 / 视频号 / YouTube Shorts）

## 前 3 秒（黄金开头）
- 短视频完播率的生死线。必须在第一句话内给出强钩子，不能"大家好，今天我们来聊聊..."。
- 有效模式："别再犯这个错了"（否定式警告）、"我发现了一个反常识的事实"、直接抛结论再倒推（"这个方法帮我XXX，原因是..."）、场景代入（"如果你也遇到过XX的情况..."）。
- 用口语、短句，像在对朋友说话，不是在念稿子。

## 正文结构（按口播节奏写，不是按书面文章写）
1. 用【】标注镜头/画面提示和口播内容分开，例如：
   ```
   【画面：出示对比图】
   口播：你看这两组数据，差别有多大...
   ```
2. 每 10-15 秒一个信息节奏点（一个论点或一个转折），避免长时间单一论述导致观众划走。
3. 中间适度制造"意外感"或反转，维持注意力（"但是——事情没有这么简单"）。
4. 语言要能"读出来顺口"：多用短句、口语连接词（"然后""结果""你猜怎么着"），避免书面语长句和从句嵌套。

## 结尾
- 明确的行动号召：关注/点赞/评论区留言/看主页链接，一句话说清楚要观众做什么。
- 如果是系列内容，可以预告下一集钩子提升关注转化。

## 时长与字数换算
- 语速约 4-5 字/秒，口播稿字数 ≈ 目标秒数 × 4.5。
- 默认输出 45-90 秒时长对应的稿子（约 200-400 字），除非用户指定其他时长。
